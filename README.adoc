= OPR Directory

Online **Open Provider Registry** catalog — apps poll, providers self-register.
See link:STATUS.adoc[STATUS].
endif::[]

== About

OpenAI-compatible HTTP is a *wire* format.
This service is the *registration directory*: public OPR records in a database, exposed at `/opr/v1/providers`.

Local runners still use link:https://github.com/dev-centr/uniprovider[UniProvider] on disk.
This directory is for **publicly reachable** endpoints only.

=== Built With

* Runtime
** link:https://www.solidjs.com/[SolidStart] / SolidJS
* Host
** link:https://www.netlify.com/[Netlify] (default Nitro preset)
** link:https://vercel.com/[Vercel] (set `OPR_DIRECTORY_NITRO_PRESET=vercel`)
* Data
** link:https://docs.turso.tech/[libSQL / Turso] (or local `file:./.data/opr.db`)

== Getting Started

[source,powershell]
----
pnpm install
copy .env.example .env
pnpm dev
----

Open http://localhost:3000 — catalog UI, `/register`, and `/opr/v1/providers`.

=== Deploy (Netlify)

1. Create a Turso database (or any libSQL URL) for production.
2. Connect this repo to Netlify; build command `pnpm build`, publish `.output/public` (see `netlify.toml`).
3. Set env vars from link:docs/ENV-VARIABLES.md[`docs/ENV-VARIABLES.md`].
4. Optional: CNAME `providers.devcentr.org` → Netlify.

=== Deploy (Vercel)

[source,powershell]
----
$env:OPR_DIRECTORY_NITRO_PRESET = "vercel"
pnpm build
vercel deploy --prebuilt
----

Set the same database env vars in the Vercel project.

== API

* `GET /health` · `GET /opr/v1/health`
* `GET /opr/v1/providers`
* `POST /opr/v1/providers` — returns `manage_token` once
* `GET|PUT|DELETE /opr/v1/providers/:id` — mutations need `Authorization: Bearer <manage_token>`
