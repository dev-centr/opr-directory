== Why not Cloudflare Workers

Cloudflare remains useful for DNS and Access in front of static docs.
This product does **not** require Workers, D1, or Pages Functions.
SolidStart + Netlify/Vercel matches the Dev-Centr house web stack and avoids a second hosting learning curve.

== Do not

* Treat this as OpenRouter (no billing, no curated marketplace).
* Register localhost / private LAN URLs (rejected by validation).
* Commit database auth tokens or admin secrets.
